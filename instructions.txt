  git pull origin main

    pip install -r requirements.txt

  Mac / Linux:

--- RULES ---

  • Use an EVEN --games count (2, 4, 50, 100 …). Odd counts >1 are rejected.
  • If grep shows nothing, run without grep first — you may have a typo or error.
  • Summary lines on stderr:
      harness timing: ...
      harness result: A <bot> W — B <bot> W — draws D — B decisive P%


--- SMOKE (~2 minutes) ---

  python -m harness --a strong --b strong_enc1 --games 4 --random-opening --opening-seed 42 --dim 8

Expect: no traceback; two harness lines printed.


--- BIG TEST — enclosed vs baseline (server) ---

Champion = strong (A). Challenger = strong_encN (B).
50 games × 4 seeds = 200 games per weight (~2–3 h each).
If B decisive % > 55%, that weight is promising. Skip enc4 unless enc1 or enc2 wins seed 42.

PowerShell — enc weight 1:

  foreach ($s in 42, 7, 99, 1234) {
    python -m harness --a strong --b strong_enc1 `
      --games 50 --random-opening --opening-seed $s --dim 8 2>&1 |
      Tee-Object -FilePath "enc1_seed$s.log" |
      Select-String -Pattern "harness result:|harness timing:"
  }

PowerShell — enc weight 2:

  foreach ($s in 42, 7, 99, 1234) {
    python -m harness --a strong --b strong_enc2 `
      --games 50 --random-opening --opening-seed $s --dim 8 2>&1 |

Mac / Linux bash (one weight):

Lines of Action — harness test instructions
============================================
Repo: https://github.com/cavedave/LinesOfAction.git
Code: Lines-of-Action-master/
Default bot: best  (= adaptive depth 3→4 + mobility_weight 5)

Run TWO parallel batches: SET A on the Windows server, SET B on the Mac.
Both machines should run SETUP + SMOKE first.


--- SETUP (both machines) ---

1. Clone or pull latest main:

   git clone https://github.com/cavedave/LinesOfAction.git
   cd LinesOfAction/Lines-of-Action-master

   — or —

   cd LinesOfAction
   git pull origin main
   cd Lines-of-Action-master

2. Python 3.10+ and virtualenv:

   Mac / Linux:
     python3 -m venv .venv
     source .venv/bin/activate
     pip install -r requirements.txt
     export SDL_VIDEODRIVER=dummy

   Windows (cmd):
     py -3 -m venv .venv
     .venv\Scripts\activate
     pip install -r requirements.txt
     set SDL_VIDEODRIVER=dummy

   Windows (PowerShell):
     py -3 -m venv .venv
     .venv\Scripts\Activate.ps1
     pip install -r requirements.txt
     $env:SDL_VIDEODRIVER = "dummy"

3. All harness commands below assume you are in Lines-of-Action-master with
   the venv active and SDL_VIDEODRIVER=dummy set.


--- SMOKE (both machines, ~1 minute) ---

Confirm imports and that best beats random:

  python -m harness --a best --b random --games 4 --dim 8

Expect: harness result line with B (random) winning 0–1 games at most.
Also expect: no Python traceback.


--- SET A — Windows server (slow / overnight) ---

Estimated total: ~6–8 hours on a typical CPU.
Save full stderr; grep the summary lines at the end.

A1) Ceiling check: best vs always depth-4 (50 games × 4 seeds = 200 games)
    Confirms adaptive is weaker than d4 but how much; reproduces ~72% d4 decisive on seed 42.

  for s in 42 7 99 1234; do
    python -m harness --a best --b minimax_d4_mob5 \
      --games 50 --random-opening --opening-seed $s --dim 8 \
      2>&1 | tee -a results_windows_A1_seed$s.log | grep -E "harness result:|harness timing:"
  done

  Windows cmd (run each seed separately):
    python -m harness --a best --b minimax_d4_mob5 --games 50 --random-opening --opening-seed 42 --dim 8
    python -m harness --a best --b minimax_d4_mob5 --games 50 --random-opening --opening-seed 7 --dim 8
    python -m harness --a best --b minimax_d4_mob5 --games 50 --random-opening --opening-seed 99 --dim 8
    python -m harness --a best --b minimax_d4_mob5 --games 50 --random-opening --opening-seed 1234 --dim 8

  Record per seed: A wins, B wins, draws, mean s/game.
  Paste the four "harness result:" lines back to the Mac session.


A2) Regression: fixed d3 mob5 vs best (50 games × 2 seeds = 100 games)
    Expect best (B) ~70–80% decisive.

  python -m harness --a minimax_d3_mob5 --b best \
    --games 50 --random-opening --opening-seed 7 --dim 8

  python -m harness --a minimax_d3_mob5 --b best \
    --games 50 --random-opening --opening-seed 1234 --dim 8


--- SET B — Mac (medium, ~2–3 hours) ---

B1) Mobility bracket at adaptive depth (50 games each, seed 42)
    Does mob5 beat mob4 and mob6 when both use selective d4?

  python -m harness --a best_mob4 --b best \
    --games 50 --random-opening --opening-seed 42 --dim 8 \

  python -m harness --a best_mob6 --b best \

  Expect: best (B) wins majority if mob5 is still optimal.

--- READING OUTPUT ---

Each batch prints two useful stderr lines:

  harness timing: N games, ... (mean X.XXXs/game, ...)
  harness result: A <bot_a> W1 — B <bot_b> W2 — draws D — B decisive P%

"A" is the --a bot; "B" is the --b bot. Colours alternate each game when
--games is even, so win counts are colour-balanced.

Full JSON on stdout includes timing.per_game_s and outcome_reasons.


--- OPTIONAL QUICK CHECKS ---

List registry bots (requires python one-liner):

  python -c "import json; print('\n'.join(json.load(open('harness/registry.json'))))"

Mobility sweep (fixed d3 only, ~30 min for weights 4,5,6):

  python -m harness sweep-mobility --baseline minimax_d3 \
    --weights 4,5,6 --games 50 --random-opening --opening-seed 42 --dim 8

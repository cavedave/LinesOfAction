Lines of Action — harness test instructions
============================================
Repo: https://github.com/cavedave/LinesOfAction.git
Code: Lines-of-Action-master/

GOAL: RL / batch self-play needs MANY games, not peak Elo.
Target: ~1 minute per game or less at 8×8.

Default bot: best  (= fast = fixed depth 3 + mobility_weight 5)
  ~20 s/game in self-play (8×8, random opening). No selective d4.

Strong/slow bot: strong  (= adaptive d3→d4 + mob5)
  ~26 s/game vs fixed d3; use only when testing strength, not for RL traces.

You can STOP any running d4 ceiling tests (best vs minimax_d4_mob5) — they are
not needed for the RL throughput path.


--- SETUP ---

  git pull origin main
  cd Lines-of-Action-master

  PowerShell:
    py -3 -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    $env:SDL_VIDEODRIVER = "dummy"

  Mac / Linux:
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    export SDL_VIDEODRIVER=dummy


--- SMOKE (~30 seconds) ---

  python -m harness --a best --b random --games 4 --dim 8

Expect: best wins all or nearly all; mean time well under 60 s/game.


--- RL THROUGHPUT TESTS (run on either machine) ---

T1) Self-play speed check (10 games — confirms ~1 min/game budget)

  python -m harness --a best --b best --games 10 --random-opening --opening-seed 42 --dim 8

  Expect: harness timing mean ~15–25 s/game at 8×8.


T2) Self-play quality smoke (50 games — bot is not broken)

  python -m harness --a best --b best --games 50 --random-opening --opening-seed 42 --dim 8

  Expect: win split roughly 50/50 (same bot both sides); few or no illegal-move draws.


T3) vs weaker baseline (50 games — mob5 beats plain d3)

  python -m harness --a minimax_d3 --b best --games 50 --random-opening --opening-seed 42 --dim 8

  Expect: best (B) wins ~70%+ decisive; still ~10–15 s/game.


T4) Optional 6×6 (faster games for huge batches)

  python -m harness --a best --b best --games 20 --random-opening --opening-seed 42 --dim 6

  Expect: mean s/game lower than 8×8.


--- PARALLEL SPLIT (if two machines) ---

Machine 1 — T2 at seeds 42 and 7 (100 games total):
  PowerShell:
    foreach ($s in 42, 7) {
      python -m harness --a best --b best --games 50 --random-opening --opening-seed $s --dim 8 2>&1 |
        Select-String -Pattern "harness result:|harness timing:"
    }

Machine 2 — T2 at seeds 99 and 1234 + T3 seed 42:
  Mac bash:
    for s in 99 1234; do
      SDL_VIDEODRIVER=dummy .venv/bin/python -m harness --a best --b best \
        --games 50 --random-opening --opening-seed $s --dim 8 2>&1 |
        grep -E "harness result:|harness timing:"
    done
    SDL_VIDEODRIVER=dummy .venv/bin/python -m harness --a minimax_d3 --b best \
      --games 50 --random-opening --opening-seed 42 --dim 8 2>&1 |
      grep -E "harness result:|harness timing:"


--- STRENGTH TESTS (optional, slow — NOT for RL batches) ---

Only if you want to compare strong vs fast:

  python -m harness --a best --b strong --games 50 --random-opening --opening-seed 42 --dim 8

  Expect: strong (B) wins majority; ~25 s/game (not ~90 s — neither side is always d4).


--- READING OUTPUT ---

  harness timing: ... (mean X.XXXs/game, ...)
  harness result: A <bot_a> W1 — B <bot_b> W2 — draws D — B decisive P%

Report: test id (T1–T4), seed, mean s/game, result line.


--- REGISTRY QUICK REFERENCE ---

  best / fast     — d3 + mob5 (RL default)
  strong          — adaptive d3→d4 + mob5
  minimax_d3      — d3 classic (weaker, slightly faster eval)
  minimax_d4_mob5 — always d4 (too slow for RL; ~90–220 s/game in mixed pairs)

--- RULES ---

  • Use an EVEN --games count (2, 4, 50, 100 …). Odd counts >1 are rejected.
  • --games 1 is allowed for a quick smoke (A always Black; unbalanced).
  • If grep shows nothing, run without grep first — you may have a typo or error.
  • Summary lines go to stderr:
      harness timing: ...
      harness result: A <bot> W — B <bot> W — draws D — B decisive P%


--- SMOKE (~2 minutes) ---

  python -m harness --a strong --b strong_proj2 --games 4 --random-opening --opening-seed 42 --dim 8

Expect: no traceback; two harness lines printed.


--- BIG TEST — projection vs baseline (run on server) ---

Compare each projection weight against strong. 50 games per seed, four seeds
= 200 games per pairing (~2–3 hours each at ~25–30 s/game).

Champion = strong (registry bot A). Challenger = strong_projN (bot B).
If B decisive % > 55%, projection at that weight is promising.

PowerShell — run one block at a time (or overnight: all three in sequence):

  # proj weight 1
  foreach ($s in 42, 7, 99, 1234) {
    python -m harness --a strong --b strong_proj1 `
      --games 50 --random-opening --opening-seed $s --dim 8 2>&1 |
      Tee-Object -FilePath "proj1_seed$s.log" |
      Select-String -Pattern "harness result:|harness timing:"
  }

  # proj weight 2
  foreach ($s in 42, 7, 99, 1234) {
    python -m harness --a strong --b strong_proj2 `
      --games 50 --random-opening --opening-seed $s --dim 8 2>&1 |
      Tee-Object -FilePath "proj2_seed$s.log" |
      Select-String -Pattern "harness result:|harness timing:"
  }

  # proj weight 4
  foreach ($s in 42, 7, 99, 1234) {
    python -m harness --a strong --b strong_proj4 `
      --games 50 --random-opening --opening-seed $s --dim 8 2>&1 |
      Tee-Object -FilePath "proj4_seed$s.log" |
      Select-String -Pattern "harness result:|harness timing:"
